| **Security** | Phone OTP authentication, server-side-only AI key handling |
| **Impact** | Removes manual slip bookkeeping for small merchants |
| **Repository** | [SlipSense](https://github.com/SOGUY144/SlipSense) |

Built as an end-to-end product — from OTP login and protected app routes, to an AI extraction pipeline that reads uploaded slips and turns them into structured financial data, visualized through dashboards and analytics pages.
